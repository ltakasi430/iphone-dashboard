# Pocket Desk – iPhone 5用ダッシュボード

> 2026-11-05更新：トップページ `index.html` はiPhone 5横置きAIモニターです。元の時計・カレンダー画面は [`classic.html`](./classic.html) に残してあります。詳しくは [`MONITOR_README.md`](./MONITOR_README.md) を参照してください。

iOS 10 Safari を想定した、外部ライブラリ不要・1ページ完結のダッシュボードです。

## 表示内容

- 時計（分単位で表示・自動更新）
- 西暦
- 年月日
- 曜日
- 現在の気温と天気（Open-Meteo API、約15分ごとに取得）
- 月間カレンダー（今日を強調・月替わり自動更新）

右上の「⚙」から各項目の表示／非表示、時計の大きさ、ダーク／ライトテーマ、天気の地域を切り替えられます。設定は端末内の `localStorage` に保存します。

## GitHub Pagesに公開する

1. GitHubで `iphone-dashboard` という **Public** リポジトリを作成します。最初に **Add a README** を有効にしても構いませんが、同名ファイルの重複には注意してください。
2. リポジトリのルートに `index.html` と `apple-touch-icon.png` をアップロードします。追加で `README.md` と `.nojekyll` を配置できます。
3. **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save** を設定します。
4. 公開が完了すると `https://<ユーザー名>.github.io/iphone-dashboard/` というURLでアクセスできます。
5. iPhone 5のSafariでURLを開き、共有ボタンから「ホーム画面に追加」。ホーム画面のアイコンから起動してください。

※ GitHub Pagesは公開サイトです。個人情報・秘密鍵・APIキーをソースコードに含めないでください。

## iPhone 5の常設設定

- iPhone本体の **設定 → 画面表示と明るさ → 自動ロック → なし** を選択（選べない場合は低電力モード等を確認）。
- 画面の明るさは低めにして、古いバッテリーの発熱や膨張がないことを確認します。
- iOS 10.3.4のSafariでの実機動作は未検証です。特に古いOSではHTTPS証明書やAPI通信に制約があり、気温だけ取得できない場合があります。
- 気温が取得できなくても時計と月間カレンダーは端末だけで動作します。
- 通信・再起動・端末のメモリ不足などにより、24時間連続表示が途切れる場合があります。
- ブラウザからディスプレイを自動点灯させたり、充電器の電源を直接ON/OFFすることはできません。

## 背景画像（iPhoneから選択）
- ダッシュボード右上の歯車 → **背景画像** → 「ファイルを選択」から端末内の写真を指定します。
- **画像の明るさ**（10〜100%）・**ぼかし**（0〜16px）・**画像の位置**（上／中央／下）を選べます。
- 写真は最大辺1000pxのJPEGに軽量化され、選んだ端末のブラウザ保存領域（localStorage）に保存されます。写真がGitHubにアップロードされることはありません。
- iPhone／Safariとホーム画面に追加したWebアプリでは、保存領域が共有されない場合があります。背景の設定は実際に普段起動する画面から行ってください。
- 保存できなければJPEG／PNGの小さな画像で再試行してください。Safariのサイトデータ消去やブラウザ変更で背景設定が消えることがあります。
- 「背景画像を削除」で写真を消せます。「初期設定に戻す」でも背景を削除します。iPhone 5の実機では未検証です。

## Iris Glass UI（iPhone 5向けのデザイン）
- ダークネイビーとシアンの半透明デザインに変更。文字・カレンダーの読みやすさを優先します。
- iPhone 5（320×568 CSSピクセル）では時計の標準文字サイズ66px、日付は通常14px。週が6段必要な月だけ13pxで表示します。
- カレンダーは原則5週、必要な月は6週。左右の矢印で月移動し、年月を押すと今月に戻ります。
- アイリスの顔を避けるため、カレンダーを画面左側に配置しています。画面下の「Iris | Coneco Navigator」は設定で表示を切り替えられます。
- 壁紙は設定 → **壁紙の構図** で「Iris向け（顔を右下に）」または「写真全体を表示」を選択できます。Iris向けは画像を120%に拡大して上寄せし、キャラクターの顔を右側に見せる設計です。画像の種類によっては手動で通常表示へ戻してください。
- 既存の背景画像や表示項目の設定は消さずに引き継ぎます。Safari iOS 10の実機での最終確認は未実施です。


## 初回アクセス時のアイリス背景
- `iris-wallpaper-default.jpg`（約20KB）を公開ファイルとして同梱しています。
- 初回アクセス時、背景を一度も設定していない端末ではアイリスが **自動表示** されます。背景を手動設定する必要はありません。
- 自分の写真を設定したことがある場合は、その端末の保存済み写真を優先します。
- 設定画面の「アイリスの標準背景に戻す」を押すと、保存済み画像だけを消去して標準背景に戻ります。
- 通信がない初回アクセスでは壁紙を取得できません。接続できている時に一度読み込めば通常はブラウザのキャッシュが使われます（保存状況に依存）。

## 点滅・アナログ秒針とカレンダーの新レイアウト

- 時刻の数字はそのまま表示し、「：」だけ1秒間隔で点滅します。右側に秒針1本だけの小さなアナログ盤を配置しました。秒針は本体の現在時刻に追従します。
- 設定画面で **「：を点滅」「アナログ秒針」** を個別にON/OFFできます。設定は従来のデータを維持したまま保存されます。
- iPhone 5の320×568では時計は標準66px、カレンダー日付は通常15px（6週月は14px）を確保します。カレンダーを画面横幅に広げ、背景のアイリスの顔が半分だけ透ける状態を避けています。
- 画像・天気API・月移動・ローカル写真保存の既存機能はそのままです。iPhone 5実機での検証は引き続き必要です。
